# engram-cap-random

Reference source for the `random@1` engram capability: a WebAssembly component
that wraps the allowlisted `wasi:random/random` import and exports a single
`next-u64` provider function.

This repository is the pinned source the
[engram-capabilities](https://github.com/immanent-ly/engram-capabilities)
registry builds from. A publish is a pull request against that registry which
moves the submodule pin to a commit here; on merge, CI checks out the pin,
builds the component with the pinned toolchain, and runs the engine's
`engram plugin publish` validation before writing the official blob.

## Build

```sh
cargo component build --release --target wasm32-unknown-unknown
```

Output: `target/wasm32-unknown-unknown/release/cap_random.wasm`.

## Layout

- `src/lib.rs` — provider implementation.
- `src/bindings.rs` — generated WIT bindings (regenerated by `cargo component`).
- `wit/` — the `plugin` world and vendored WASI dependencies.

## Versioning

The exported provider version is the source of truth. The registry manifest's
`version` must equal it, and the engine's publish validation rejects a mismatch.
Bumping the version means changing the export and opening a new registry PR that
moves both the submodule pin and the manifest `version` together.
